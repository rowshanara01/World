1. Clone the repository

   ```bash
   git clone https://github.com/rowshanara01/your-repo-name.git
   ```

2. Go into the project folder

   ```bash
   cd your-repo-name
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code for automatic reload while editing.

No installation or build step is needed.

### Deploy with GitHub Pages

1. Go to **Settings → Pages** in your repository
2. Under **Source**, choose the `main` branch and the `/ (root)` folder
3. Save. Your site will be live at `https://rowshanara01.github.io/your-repo-name/`

You can also deploy it for free on **Vercel** or **Netlify** by importing the repository.
